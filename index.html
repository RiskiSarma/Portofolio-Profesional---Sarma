Penerapan analisis data pada sistem nyata yang telah dibangun

Analisis Data Terintegrasi dalam Sistem Nyata

Setiap sistem yang dibangun tidak hanya berfungsi sebagai aplikasi web, tetapi juga menerapkan proses analisis data secara nyata — mulai dari identifikasi kebutuhan, pengumpulan, pembersihan, hingga visualisasi sebagai dasar pengambilan keputusan bisnis.

● BNSP Data Analyst

Proses Analisis Data

Diterapkan langsung pada projek nyata yang telah dibangun

Seleksi & Kebutuhan Data

SKDB: Dataset Kaggle memiliki 20 kolom — dianalisis relevansinya terhadap kebutuhan guru, kemudian dipilih 10 kolom yang sesuai dengan indikator penilaian: age, motorik kasar, motorik halus, komunikasi, ekspresif, menyimak, Kemampuan Pra Akademik, membaca, sosial skill, dan growth.

SI Pelatihan: Google Form memiliki 15 kolom — dipilih 12 kolom yang relevan untuk kebutuhan sistem pendataan peserta pelatihan.

SKDB SI Pelatihan

Pengumpulan Data

SKDB: Dataset dikumpulkan dari Kaggle sebanyak 80.000 data. Data testing dikumpulkan dari observasi langsung guru di lapangan — guru menginput hasil penilaian siswa ke sistem secara real-time.

SI Pelatihan: Data peserta dikumpulkan melalui Google Form kemudian diproses untuk diimport ke dalam sistem.

SKDB SI Pelatihan

Integrasi & Pembersihan Data

SKDB: Dataset Kaggle diintegrasikan dengan standar penilaian guru. Preprocessing meliputi normalisasi nilai, penanganan missing value, lalu data dibagi menjadi data training & data testing.

SI Pelatihan: Nama kolom hasil Google Form disesuaikan melalui query SQL agar sesuai dengan struktur kolom tabel database sebelum proses import — cleaning data nyata di lingkungan produksi.

SKDB SI Pelatihan

Klasifikasi & Validasi Model

SKDB: Data training digunakan untuk melatih model Decision Tree CART. Data testing dari observasi guru digunakan untuk menguji model — sistem otomatis mengklasifikasikan tingkat keterlambatan siswa: Normal / Ringan / Sedang / Berat pada 3 aspek: motorik, kognitif, dan bahasa.

SKDB

Visualisasi Data & Dashboard

SKDB: Hasil klasifikasi ditampilkan di dashboard sistem — guru dapat langsung melihat siswa mana yang terdeteksi mengalami keterlambatan beserta aspeknya sebagai dasar tindakan intervensi yang tepat.

DeCafe: Data transaksi penjualan divisualisasikan dalam bar chart interaktif — menampilkan porsi penjualan per menu sehingga pemilik cafe dapat mengidentifikasi produk terlaris dan mengambil keputusan bisnis berbasis data.
